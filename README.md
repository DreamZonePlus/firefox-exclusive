# متصفح Firefox بجلسة حصرية — "واحد في الوقت" بدون كلمة سر

غلاف حول حاوية [jlesage/docker-firefox](https://github.com/jlesage/docker-firefox) يضيف ميزة غير موجودة في الحاوية الأصلية:

- **الدخول بدون كلمة سر.**
- **أول من يفتح الصفحة يحجز المتصفح لنفسه** ويُحجب الدخول على أي شخص آخر.
- يرى المحجوبون صفحة عربية أنيقة تُعِيد المحاولة تلقائياً كل بضع ثوانٍ، ويدخلون تلقائياً بمجرد تحرر الدور.
- الجلسة محكومة بحد أقصى للمدة، ويُحرَّر الدور أيضاً بعد مغادرة المستخدم بفترة سماح قصيرة (فرصة ليعود).

## البنية

```
المستخدم ──► gateway (بوابة الحجز) ──► firefox (حاوية jlesage/firefox)
              المنفذ 8080               المنفذ الداخلي 5800 (غير منشور)
```

البوابة تعطي أول زائر كوكي جلسة عشوائي (بدون كلمة سر). أي طلب أو اتصال WebSocket من
صاحب الكوكي يُمرَّر إلى الحاوية، ومن غيره يستقبل صفحة "مشغول".

## الإعدادات (متغيرات البيئة لخدمة gateway)

| المتغير | الافتراضي | الوظيفة |
| --- | --- | --- |
| `LOCK_MAX_MINUTES` | `60` | الحد الأقصى لجلسة المستخدم الواحد بالدقائق (تُقبل كسوراً مثل `0.5`). بعده يُطرد ويُحرَّر الدور لغيره، ويُمنع هو من الدخول فوراً لفترة قصيرة. |
| `LOCK_GRACE_SECONDS` | `120` | بعد أن يغلق المستخدم الصفحة، كم ثانية يبقى الدور محجوزاً له قبل أن يُتاح لغيره. |
| `BUSY_RETRY_SECONDS` | `10` | كل كم ثانية تُعِيد صفحة "مشغول" المحاولة تلقائياً. |

### سيناريوهات شائعة

- **"الأول يستخدم حتى يخرج"** (الافتراضي): اترك الإعدادات، أو ارفع `LOCK_MAX_MINUTES` (مثلاً `480`) وخفّض `LOCK_GRACE_SECONDS` (مثلاً `60`).
- **"فترات ثابتة"** (مثلاً كل مستخدم 30 دقيقة كاملة حتى لو خرج مبكراً):
  `LOCK_MAX_MINUTES=0.5` و `LOCK_GRACE_SECONDS=1800` (أي أسبقها مساوية للمدة القصوى أو أكبر).
- **"حجب فوري بعد الخروج"**: `LOCK_GRACE_SECONDS=5` مع أي قيمة للحد الأقصى.

## التشغيل

### Docker عادي

```bash
cd firefox-exclusive
docker compose up -d --build
```

ثم افتح: `http://<عنوان-الخادم>:8080` (أو المنفذ الذي عيّنته).

### عبر Coolify

1. انقل هذا المجلد إلى مستودع Git خاص (أو استخدمه من مكانه).
2. في Coolify أنشئ مشروعاً جديداً من نوع **Docker Compose** واربطه بالمستودع.
3. **مهم جداً — ربط الدومين:** عند النشر سيظهر أكثر من خدمة (firefox + gateway).
   الدومين يجب أن يُربط **بخدمة `gateway` فقط** على المنفذ **8080**:
   - ادخل على خدمة gateway → قسم ** Domains** → أضف الدومين مع تحديد المنفذ 8080.
   - تأكد أن خدمة `firefox` **ليس عليها أي دومين ولا منفذ منشور**.
   - إذا رُبط الدومين بخدمة firefox فسيدخل الجميع معاً بلا أي حجز (هذا الخطأ الشائع الأول).
4. يتكفل Coolify/Traefik بـ HTTPS وتمرير WebSocket تلقائياً.

## التحقق من أن المرور يمر عبر البوابة

بعد النشر، تحقق فوراً قبل تجربة المستخدمين:

```bash
# 1) حالة البوابة مباشرة (نقطة نهاية عامة):
curl -s https://دومينك.dev/__gateway/status
# متوقع: {"gateway":"firefox-exclusive","status":"free",...}

# 2) ترويسة التعريف على أي استجابة:
curl -sI https://دومينك.dev/ | grep -i x-fx-gateway
# متوقع: x-fx-gateway: 1   ← وجودها يعني أن المرور عبر البوابة.
# غيابها يعني أن الدومين متصل بحاوية firefox مباشرة — راجع ربط الدومين.

# 3) محاكاة مستخدمين اثنين (جلسات منفصلة):
curl -s -o NUL -w "%{http_code}\n" -c /tmp/c1 https://دومينك.dev/   # متوقع: 200
curl -s -o NUL -w "%{http_code}\n" -c /tmp/c2 https://دومينك.dev/   # متوقع: 503
```

نقطة النهاية `/__gateway/status` تُظهر أيضاً: هل الدور محجوز، المتبقي من الجلسة بالدقائق،
عدد الاتصالات النشطة، وقيم الإعدادات — مفيدة للمراقبة والتشخيص.

## ملاحظات أمنية

- لا تنشر منافذ حاوية `firefox` (5800/5900) — وإلا يُتجاوَز نظام الحجز بالكامل.
- ملف `docker-compose.yml` يعطّل VNC داخلياً (`VNC_LISTENING_PORT=-1`) لهذا السبب.
- استخدم HTTPS عبر الدومين في Coolify؛ بعض مزايا الواجهة (مزامنة الحافظة، الإشعارات، التثبيت كتطبيق) تعمل فقط في سياق آمن.
- بما أن الدخول بلا كلمة سر، فإن **أول طلب يصل** هو من يحجز الدور — أي أن برامج المسح الآلي قد تحجز الدور مؤقتاً إذا وصلت إلى العنوان. المهلة القصيرة بعد المغادرة تجعل الأثر محدوداً؛ ولتقليله استخدم دوميناً غير معلن.
